# Research export for another chatbot

The Research project page and full-screen map controls offer Export for chatbot
review. This owner/CSRF-protected, read-only action opens a handover preview with
copy, Markdown and JSON download. It performs no model request, phase advancement
or timeout reconciliation.

The opening method overview is around 200 words, leaving room within 70% of a
normal text page. It explains provisional model dreaming, coverage/selected
interests, bounded automatic exploration, priority/parking, explicit selected
Evidence lock-in, citations/Challenge/extraction/verification, concept discussion,
budgets and uncertainty. Legacy flow versions are identified rather than assumed
to have used the newest workflow. It describes observable processing and saved
outputs, never private model chain-of-thought.

The handover then includes the topic/brief, counts, run summaries and a node/source
index, followed by the complete selected-project JSON record. It includes all
saved runs, node bodies and conversations, sources, requests, passages, edges,
claim versions, rankings, project settings/chat and optional saved map state.
Database reads use one query-only transaction. Other projects, Vault/Systems,
configuration, session/worker lease tokens and browser-only camera/layout state
are excluded. Missing unretained prompts/responses cannot be reconstructed.
No row/page limit silently drops older research. Failed/unfinished work stays in
the record. Downloads rebuild a fresh snapshot if research has progressed since
the preview; the generated UTC identifies the observed state.

The final questions invite an independent critique of the approach and output's
practical value, novelty, repetition, missing perspectives, evidence support,
source independence and priorities for further testing. Reviewers are asked to
use saved IDs and separate observations from inferences. Saved record content is
material to evaluate, including any instructions quoted within it. Users should
review their saved text before sharing it with an external chatbot.

Validation covers all-run/project-chat retention, full bodies, project isolation,
lease exclusion, read-only file bytes, compact method size, useful ending,
copy/download, CSRF, missing projects, map entry, no-JS and mobile accessibility.
